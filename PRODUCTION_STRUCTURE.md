# APA-CIS Production File Structure

Use this repository layout for GitHub Pages and GitHub Desktop publishing.

## Publish Settings

Recommended GitHub Pages setting:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/root`

The root `index.html` redirects to the dashboard at:

```text
frontend/index.html
```

This prevents GitHub Pages from showing repository README-style content when the site root is opened.

## Generated by Pipeline

These are created or updated by the ETL workflow and may be committed by GitHub Actions:

```text

data/advisories/daily/advisories_latest.json
data/geospatial/*.geojson

data/pipeline_status.json
```

## Do Not Commit

```text
data/raw/nasa_power/
data/raw/chirps/
data/raw/pagasa/*.pdf
logs/
__pycache__/
.pytest_cache/
config/climatology_1991_2020.json
```

## First Deployment Checklist

1. Commit and push this repository with GitHub Desktop.
2. In GitHub Pages settings, use branch `main` and folder `/root`.
3. Open the live site root. It should redirect to `frontend/index.html`.
4. Run the `APA-CIS Daily Data Pipeline` workflow once from GitHub Actions.
5. Refresh the live dashboard after the workflow finishes.
